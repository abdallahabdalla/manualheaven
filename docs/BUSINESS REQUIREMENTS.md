BUSINESS REQUIREMENTS SUMMARY
BR-1: Product Browsing

System shall allow users to view a catalog of automotive apparel products.

BR-2: Order Simulation

System shall allow users to simulate placing an order for a selected product.

BR-3: Order Lifecycle Simulation

System shall simulate order status transitions from Created → Processing → Completed.

BR-4: Order Confirmation

System shall display a confirmation summary after order completion.

BR-5: UI Consistency

System shall provide a clean, modern storefront UI inspired by Shopify.
