Stakeholder Map — ManualHeaven

Primary Stakeholders (direct users)
1. Customer (End User)
Browses automotive apparel
Adds items to cart
Places orders
Receives confirmation

Needs:

Easy browsing experience
Clear product presentation
Simple ordering flow
Trust/confirmation feedback

2. Store Owner (System Admin role – simulated)
Receives order requests (simulated)
“Processes” orders manually in UI logic
Updates order status (simulated)

Needs:

Simple order visibility
Ability to change order status (JS simulation)
Clear order structure

Secondary Stakeholders
3. Developer
Builds and maintains system
Defines structure and logic
Improves UX and simulation flow

Needs:

Clean architecture
Modular JS structure
Maintainable code

System Stakeholders (non-human)
4. Browser (Execution Environment)
Runs HTML/CSS/JS
Stores state (optional localStorage)
5. GitHub Pages (Hosting Platform)
Hosts static site
No backend support
